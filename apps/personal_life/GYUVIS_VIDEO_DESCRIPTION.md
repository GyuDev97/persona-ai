# 규비스는 어떻게 만들었을까? — 영상 설명란 초안

규비스는 Python 기반의 개인 AI 비서 프로젝트입니다. 음성 호출, 작업 자동화, PC 제어, 웹 화면을 하나의 흐름으로 연결하고 있습니다.

## 영상에서 보여준 구조

```text
[PC 계층]
마이크 → PC Wake Listener → HUD·자막·TTS·PC/웹 실행
                 ↓
[GyuVIS Core]
FastAPI 명령 API → 의도 분류·브리핑·작업 서비스
                 ↓
[데이터·에이전트 계층]
SQLite(일정·메모리·작업) + PC Agent Runner(뉴스·에이전트 작업)
```

## 사용한 기술

- Python
- sounddevice (마이크 입력)
- SpeechRecognition 및 Google Speech Recognition (음성 인식)
- FastAPI (웹 화면과 서버 연결)
- Codex (기능 구현과 오류 해결 보조)

## Codex에 요청한 방식 예시

Codex에게 전체 서비스를 한 번에 만들어 달라고 하기보다, 구조도에서 구현할 섹션 하나를 고른 뒤 아래 네 단계를 반복했습니다.

1. 사용자 행동과 기대 결과를 한 장면으로 정의합니다.
2. 입력 장치, 수정 범위, 기존 기능 보존 같은 제약을 붙입니다.
3. 실패하면 실제 영상과 콘솔 로그를 함께 전달합니다.
4. 수정 파일과 통과 기준을 확인합니다.

```text
[현재 상태]
Python·FastAPI 기반 개인 AI 비서 프로젝트다.

[목표]
PC 마이크를 계속 듣고, '일어나'라는 호출어가 인식되면 규비스 화면을 열어줘.

[수정 범위와 제약]
마이크 리스너와 실행 배치만 수정해줘. 기존 명령 처리, 데이터, 화면 동작은 유지해줘.
노트북 내장 마이크를 사용하고, 음성 입력과 인식 결과를 콘솔 로그로 확인할 수 있게 해줘.

[완료 기준]
한 번의 호출로 화면이 열려야 한다.
고정된 녹음 구간 때문에 호출어가 잘리지 않도록, 말이 시작될 때부터 녹음하고 말이 끝난 뒤 인식해야 한다.
```

이 프로젝트의 코드와 사용 환경은 계속 수정 중입니다. 다음 영상에서는 설치부터 직접 따라 만드는 흐름으로 정리해 보겠습니다.
