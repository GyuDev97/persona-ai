# Jarvis Gesture HUD Electron App v2

## 실행 방법

```bash
npm install
npm start
```

## 들어간 기능 5개

1. 손 좌/우 스와이프 → 듀얼모니터 창 이동
2. 손 따라 파티클 HUD 구체 이동
3. 양손 펼치기 → 창 최대화
4. 손가락 집기(Pinch) → 창 잡아서 드래그
5. 한국어 음성 명령

## 키보드 테스트

- 오른쪽 방향키: 다음 모니터
- 왼쪽 방향키: 이전 모니터
- 위쪽 방향키: 최대화
- 아래쪽 방향키: 최소화
- T: 항상 위 토글
- V: 음성 인식 켜기/끄기

## 한국어 음성 명령 예시

- "오른쪽"
- "왼쪽"
- "최대화"
- "최소화"
- "복원"
- "항상 위"

## 참고

Electron의 음성 인식은 환경에 따라 Web Speech API가 동작하지 않을 수 있습니다.
안 되면 Chrome 브라우저 기반 테스트 또는 별도 STT API 연동이 필요합니다.
